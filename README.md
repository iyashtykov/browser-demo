# browser-demo

Static page for testing Codio remote browser sessions (guide Browser tab, `codio-tools browser push/pull`).

Page: https://iyashtykov.github.io/browser-demo/

It takes a CSV with `name,score` rows, marks each row `passed` (score >= 70) and offers `report.csv` for download. No sign-in, no server: everything runs in the page.

## Codio assignment

Files in `assignment/`:
- `data.csv` — put in the project root.
- `check_report.sh` — put in `.guides/secure/`, used by a Standard code test (`bash .guides/secure/check_report.sh`).

Guide section layout:
- Panel 0: Browser tab, URL `https://iyashtykov.github.io/browser-demo/`, files to send: `data.csv`, Kiosk off.
- Panel 1: terminal (for the pull command) + guide.

Section text:

> 1. In the Browser tab click **Upload CSV**. The file dialog opens in the uploads folder: pick `data.csv`.
> 2. Check the table and click **Download report.csv**.
> 3. In the terminal run:
>    `codio-tools browser pull report.csv --to submission`
> 4. Click **Check It!**.

Expected `submission/report.csv`:

```
# generated by browser-demo from data.csv
name,score,passed
alice,82,yes
bob,67,no
carol,91,yes
dave,74,yes
TOTAL,314,3
```
